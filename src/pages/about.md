## 你好，我是 Dieraun

白天写界面，晚上写字。大多数时候，我在和浏览器里那些看不见的细节打交道：一行文字应该落在哪里，一次点击之后应该发生什么，一个页面在慢网络下还能不能保持体面。

这个博客叫 **SU2.Dieraun**。名字没有什么复杂的来历，只是把常用的账号名和一点个人标记放在一起。它不追热点，也不打算做成一个内容农场，只是把那些真正想清楚的事，慢慢写下来。

## 我在意的事

### 前端工程

我喜欢原生 Web 的能力，也相信“少一点”往往需要更高的判断力。对设计系统、可访问性、性能预算，以及那些用户不会注意到、但会感受到的细节保持兴趣。

### 设计与排版

屏幕阅读和纸张阅读不一样。字号、行高、留白、对比度，这些看起来枯燥的参数，决定了一个人愿不愿意在页面上多停留五分钟。

### 写作与记录

写作是整理思考的方式。很多想法在脑子里是模糊的，落到句子里才会暴露问题。这个博客首先是为我自己写的，如果恰好对你有用，那很好。

## 这个站

纯静态站点，没有后端，没有数据库，也没有第三方评论系统。文章写在 Markdown 里，由一个小构建脚本生成 HTML，最后托管在 GitHub Pages 上。样式和交互都用原生 HTML、CSS、JavaScript 完成。

我希望它加载得快、读起来安静，在手机和电脑上都体面，在亮色和暗色里都舒服。
